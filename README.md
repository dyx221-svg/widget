# Пульт руководителя ГЛК — демо на платформе BARS

Живое демо: https://glk-dashboard-bars.vercel.app

Статический сайт без сборки: HTML + CSS + чистый JS. Данные симулируются в браузере,
3D-карта — Three.js с CDN (через importmap).

## Деплой

Репозиторий подключён к Vercel: пуш в `main` автоматически обновляет продакшен,
пуш в другую ветку создаёт превью со своей ссылкой. Сборки нет — файлы отдаются как есть.

## Запуск локально

```
python3 -m http.server 8765
```

Открыть http://localhost:8765

## Файлы
- `js/sim.js` — модель дня курорта: гости, тарифы, подъёмники, трассы, прокат, шкафчики, кафе, школа, парковка, турникеты. В боевой версии заменяется потоком событий из ППС «Барс».
- `js/map.js` — 2D-схема курорта: трассы цвета «пробок», человечки, кабинки, очереди, подсказки при наведении. Отсюда же берётся геометрия для 3D.
- `js/map3d.js` — 3D-карта: низкополигональная гора, лыжники, подъёмники, посёлок, парковка.
- `js/ui.js` — KPI, графики, лента турникетов, прокат, шкафчики, умные подсказки.
- `css/styles.css` — фирменная тема BARS (графит + зелёный), адаптив до 375 px.

## Управление
- Скорость времени: пауза / ×1 (реальное) / ×60 / ×300.
- Сценарии: обычная суббота, праздничный пик, ветер и метель (остановка гондолы).
- Карта: переключатель 3D / 2D.
